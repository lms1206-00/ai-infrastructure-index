# 01. Data Acquisition

## 목적

AI Infrastructure Custom Index 구축에 필요한 데이터가
실제로 확보 가능한지 검증한다.

## 이번 단계에서 확인할 데이터

- 기업명
- 티커
- CIK
- 거래소
- 산업분류
- 시가총액
- 거래량
- 재무제표
- SEC 10-K 사업내용

## 주요 데이터 출처

- SEC EDGAR
- SEC Company Facts API
- Yahoo Finance

## 이번 단계의 완료 기준

1. 미국 상장기업 마스터 데이터 확보
2. 티커와 CIK 연결
3. SEC 재무데이터 수집 가능 여부 확인
4. 주가 및 거래량 수집 가능 여부 확인
5. 확보 가능한 데이터 목록 정리
