# "특별편출 0건" 결론 — 근거 검증 보고서 (2026-07-27)

기존 파일 미변경. 근거 데이터는 기존 가격패널(`prices_close_100.csv`=87+13 통합),
`suspension_audit_100.csv`, `corporate_actions.csv`, `backtest_diagnostics.csv` 만 사용.
점검표: `sr_suspension_100.csv`, `sr_corporate_actions.csv`, `sr_event_replay.csv`
(코드 `24_special_removal_verification.py`).

> **핵심 정정**: "특별편출을 적용할 사례 0건"은 **"공식적으로 사건이 없었다"가 아니라
> "현재 사용한 데이터(현재 100 티커의 조정종가 + 확인 가능한 기업행위 목록)에서
> 탐지되지 않았다"** 이다. 공식 거래정지·상장폐지 고시와 전수 대조하지 않았고,
> 유니버스가 현재 생존 티커라 과거 소멸기업은 원천 미포함(생존편향)이다.

| 연속 가격 결측 구간·최대 결측일 | **내부결측 합계 0, 최대 내부결측 0거래일** | PRICE_DATA_VALIDATED |

| 거래소 휴장일 vs 개별 결측 구분 | QQQ 거래일을 정본 달력으로 사용 → 휴장일 구조적 배제 | PRICE_DATA_VALIDATED |

**요약**: 100종목 조정종가 패널은 상장~현재 구간에 **내부 결측이 전혀 없고**(따라서 장기
거래정지로 의심할 결측 구간 자체가 없음), 중도 종료도 없다. 단 이는 **가격 결측 기반 탐지**
이며, 개별 거래량·공식 거래정지 고시와는 대조하지 않았다(단기 halt는 일별 종가로 탐지 불가).

## 3. 가격 데이터 처리 검증

| 항목 | 결과 |
|---|---|
| adjusted close 사용 | **예** — 전 다운로드 `auto_adjust=True`(05_download_prices, 08, 20) |
| 주식분할·배당 자동 반영 | **예** — auto_adjust가 배당·분할 반영 |
| 합병/분할/티커변경 전후 가격 연결 | **케이스별 상이**: COHR는 연속(조정 stitch), **ONTO는 미연결**(신티커 이력 없음→전환 전 제외), GEV/CEG는 분할일부터 시작(정상) |
| 가격 종료 종목을 마지막가로 유지 | **해당 사례 0건**(중도 종료 종목 없음, 전 종목 패널끝까지 거래) |
| 결측 수익률 0% 처리 | 내부 결측이 0건이라 **발생하지 않음**. (설계상 상장후 결측은 ffill→flat→그 구간 0%가 되나, 실제 채워야 할 내부 결측 없음) |
| forward fill 대상·최대기간 | 상장 후 구간 결측만 ffill(선행 NaN 유지, **bfill 금지**). 실제 채운 내부결측 = **0거래일**(채울 대상 없음) |

**해석**: 조정종가라 분할·배당은 자동 처리. 다만 **티커변경이 yfinance에서 stitch되는지에
따라 연결 품질이 다르다** — COHR(=II-VI 존속)는 연속, ONTO(NANO/RTEC 역합병)는 신티커라
이력이 끊겨 전환 전 구간이 제외된다(5절). ffill은 실제로 채운 구간이 없어 수익률 왜곡 없음.

## 4. "특별편출 0건"의 의미 (해당 항목 복수 표시)

| 보기 | 해당? | 근거 |
|---|---|---|
| **A. 공식 거래정지·상장폐지·M&A 자료 전수 대조 → 실제 사건 없음** | **아니오** | 공식 halt/상장폐지 고시와 대조하지 않음(가격 결측 추정) |
| **B. 가격 결측·중도 종료 기준 탐지 사건 없음** | **예** | 내부결측 0·중도종료 0·장기정지의심 0 (`sr_suspension_100`) |
| **C. 사건은 있었으나 해당 시점 Top30가 아니어서 지수 영향 없음** | **예(부분)** | 기업행위 25건 중 removal-type 0건. 티커변경(ONTO/COHR)은 편출이 아니라 승계/제외로 처리, 분할(GEV/CEG)은 Top30 이력 0 |
| **D. 현재 생존기업 유니버스라 과거 소멸기업 원천 미포함** | **예** | 100종목 전부 현재 SEC 티커. 과거 폐지·피합병 소멸 종목은 구조적 부재(생존편향) |

→ **결론: B + C + D 에 해당하며, A(공식 전수대조)에는 해당하지 않는다.**

## 5. 실제 사건 재현 (`sr_event_replay.csv`)

### ONTO (티커변경 2019-10-25, NANO/RTEC→ONTO) — **Top30였고, 제외로 처리됨**
- 가격 first_valid = **2019-10-28** (신티커 ONTO 이력이 그 이전 없음).
- 가중치 파일상 ONTO는 2011~2025 32개 스냅숏에 back-projection(존속 CIK 재무).
- **효력일 직전 Top30 = 2019-03-31**에 편입돼 있었으나, `backtest_diagnostics.csv` 확인 결과
  **2011~2019 15개 리밸런싱(2019-03-31 포함)에서 "ONTO" 진입가 없음 → 제외·잔여 재정규화**.
  → 즉 백테스트는 전환 전 구간을 **종목 제외**로 처리(교환비율 0.8042 미모델). 첫 유효
  Top30 반영은 신티커 가격이 생긴 이후.
- **정확성 판정**: look-ahead는 없으나(가격 없는 종목 미보유), 전환 전 편입분이 지수에
  반영되지 못한 **티커연속 아티팩트**(생존편향의 일부). 과대·과소 방향은 제외+재정규화라
  중립이나, 원자료 한계로 남김.

### COHR (사명변경 2022-07-01, IIVI→COHR) — **연속 가격, 효력일엔 Top30 아님**
- 가격 first_valid = **2009-06-01**(존속 II-VI 이력을 조정 stitch) → **연속 보유 가능**.
- Top30 = 2011~**2021-09-30**(31개). 효력일(2022-07-01) 시점엔 이미 Top30 밖(직전 편입
  2021-09-30). → 사명변경이 활성 편입종목에 영향을 준 시점 아님.
- Top30였던 2011~2021 구간은 연속 조정가로 정상 처리. **정확 처리(가격 연결됨).**

### GEV (분할 2024-04-02) / CEG (분할 2022-02-01) — **Top30 이력 0 → 지수 무영향**
- 둘 다 분할일부터 가격 시작, **Top30 편입 이력 0건**. 과거 리밸런싱에 미편입(PIT 준수).
  → 지수에 영향 없음.

## 6. 최종 결론 (증거 수준 반영)

**수정 전**: "…특별편출을 적용할 거래정지 또는 상장폐지 사례는 탐지되지 않았다."

**수정 후(권장)**:
> "현재 후보 유니버스 100개(현재 SEC 티커)의 **조정종가 패널과 확인 가능한 기업행위 목록**을
> 점검한 결과, **가격 결측·중도 종료 기준으로는** 백테스트에 특별편출을 적용할 거래정지·
> 상장폐지·합병소멸 사례가 **탐지되지 않았다**. 확인된 기업행위 25건은 모두 신규상장/재상장/
> 티커변경/존속형으로 removal-type이 아니었고, 그중 Top30에 관련된 사례(ONTO 티커변경)는
> 특별편출이 아니라 가격 부재에 따른 제외·재정규화로 처리되었다. 단 (i) **공식 거래정지/
> 상장폐지 고시와 전수 대조하지 않았고**(가격 결측 기반 추정), (ii) 유니버스가 현재 생존
> 티커라 **과거 소멸기업이 원천적으로 포함되지 않았다**(생존편향). 따라서 이는 '사건이
> 없었음'이 아니라 **'현재 사용한 데이터에서 탐지되지 않음'**으로 한정한다."

## 잔여 한계
1. 거래량·공식 halt/상장폐지 고시 미보유 → 정지·폐지의 **공식 확정 불가**(proxy·결측추정만).
2. 생존편향 미제거 → 과거 소멸기업 원천 부재. **PIT 유니버스 재구축**이 근본 해법(미구현).
3. 티커변경 stitch 품질이 데이터 소스(yfinance) 의존 → ONTO형은 전환 전 구간 제외로 처리됨.
4. 현금/주식교환비율 등 M&A 조건은 백테스트에서 **모델링하지 않음**(존속 티커 조정가만 사용).
